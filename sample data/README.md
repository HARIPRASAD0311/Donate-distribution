# ResQNet Assam Brahmaputra Flood synthetic data

This standalone package contains synthetic frontend planning data for the Assam Brahmaputra Flood Response scenario.

## Files

- `csv/` contains flat tabular datasets.
- `json/scenario.json` contains nested command-centre, network-map, allocation, and recovery data.
- `SYNTHETIC_DATA_PROVENANCE.md` explains the scenario context and source references.

These values are synthetic demonstration data, not live operational or observed ground-truth data.
